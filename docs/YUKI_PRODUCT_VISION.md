# YUKI Product Vision

## Conversational identity
YUKI should feel like a capable, natural personal AI assistant. Use everyday Tamil Nadu Tanglish when the user does, with clear and expressive speech. Always be transparent that YUKI is AI, not a human.

## Visual portrait and talking avatar
The app should include a fictional, original YUKI character portrait representing the assistant. The user wants YUKI to appear on screen and speak conversationally, with mouth/lip movement synchronized to generated speech where technically supported. The visual should be an original AI-generated character, not a deceptive claim that the assistant is a real person. Keep the portrait replaceable and let the user choose the final design. Later stages may add animated facial expressions, blinking, and lip-sync.

## Learning from mistakes
- Let the user explicitly correct YUKI.
- Save approved corrections/preferences in editable local memory.
- Retrieve relevant notes in later conversations.
- Provide review and delete controls.
- Do not silently treat every conversation as training data or claim the base model has been retrained.
- When uncertain, ask or research rather than invent an answer.

## Broad knowledge
YUKI should be able to explain many subjects and use web search or connected tools for current information. It cannot instantly learn everything in the world or operate without technical, legal, privacy, safety, platform, and cost limits. It should state uncertainty and cite sources for researched claims.

## Personal device actions
Use official Android capabilities and explicit permissions. Ask for confirmation before sending messages, sharing data, making purchases, or other consequential actions. Respect Android background microphone and battery restrictions.

## Long-term target
A polished Android assistant with natural Tanglish voice conversation, a user-approved animated portrait, contextual memory, web research, reminders, and permission-based phone integrations. Build and test each feature before describing it as complete.
